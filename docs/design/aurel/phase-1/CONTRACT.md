# Phase 1 — a workspace around the world

The primary job is finding a place, choosing a relevant tool, and reading its evidence without losing the map. This phase reorganizes existing capabilities. It does not invent project storage, observations, new feeds or paid services.

## Three directions

The local [exploration sheet](explorations.html) compares the same Dehradun search → inspect → compare → save/author workflow. The geographic drawing is a schematic layout specimen, not geographic evidence. The interaction samples switch between these tasks so reading order can be judged consistently.

- **Observatory — selected default.** Persistent search across the top; four quiet task destinations on the left; existing inspection on the right. Near-opaque graphite reading surfaces protect contrast over bright imagery. Tool labels remain visible. It gives the map the central open space and avoids theatrical telemetry during ordinary research.
- **Field — retained as appearance.** The same action positions with warm light surfaces, dark type, larger contrast separation. Useful for daylight preparation and long reading. It changes presentation only; no selections or camera state are reset.
- **Instrument — retained as appearance.** Compact framing and cool mineral accents for expert use. Existing cinematic/HUD overlays remain available. Dense presentation must not reduce control hit areas or replace source status with decorative activity.

Observatory is selected because it avoids the attention competition of the light panels and the extra ornamentation of the instrument view. This is a design rationale; live application task checks, rather than the specimen alone, are the release gate.

## Checkable contract

| Area           | Constraint                                                                                                 |
| -------------- | ---------------------------------------------------------------------------------------------------------- |
| Identity       | Original AUREL mark, Manrope interface, JetBrains Mono numeric metadata; no copyrighted show assets        |
| Search         | Exactly one existing location-search input; always visible on desktop/phone; existing geocoders and errors |
| Navigation     | Explore, Compare, Plan, Library lead to existing owners; every legacy tool remains reachable               |
| Inspector      | Existing mounted panels retain state; one disclosed panel; no parallel fake details                        |
| Appearance     | Local preference changes only presentation; keys, data, styles, saved links remain untouched               |
| Desktop        | 1440×900 and 1280×720; readable header/search and no overlapping controls                                  |
| Phone          | 390×844; map plus one inspector with collapsed/half/full sizes; search and task navigation reachable       |
| Short viewport | 667×375 or equivalent zoom; scrollable controls, accessible close/recovery actions                         |
| Accessibility  | Keyboard navigation, visible focus, readable control labels, reduced motion; 44px phone controls           |
| Evidence       | Preserve source/time/coverage truth; free-only status means policy, never fabricated live data             |

## Content states

- Loading: preserve the search field and show the existing busy state/status.
- Empty: no selected panel leaves the map usable; unavailable imagery directs the user to its existing layer.
- Error: geocoder errors remain inline and announced, and the same field accepts correction.
- Partial: offline map and provider-blocked states retain their existing honest labels.
- Success: owner-published location and map source status update; no artificial success banner.
- Permission: provider actions still follow Phase 0; appearance/navigation never requests access or starts a paid feed.

Browser evidence and any limitations must be recorded after integration. This document does not certify untested states.
