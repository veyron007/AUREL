AUREL / Identity exploration / 02

Lamplight.
The parlor with one lamp lit.

Brief: keep the globe the only bright thing, give the console a room instead of one flat glass, and make the only glowing colour whatever you can press. Mindspace (sheet 01) was the starting point.

Reference palette sampled from Marvel Television’s VisionQuest key art (Disney+, October 2026): oxblood and near-black interiors, a mustard-ochre armchair, porcelain-white Vision, petrol-teal wallpaper, amber honeycomb stained glass and a thin letterspaced title with a scanline cut.

Signature details

  1. Brass seam. Brass seam, the one signature: .ui-rail__item--on gets box-shadow: inset 3px 0 var(--accent), 0 0 0 1px var(--accent-dim) with no gradient fill (replace the current #d7b778 literals in aurel.css lines 110-116); the active dock button gets box-shadow: inset 0 -3px var(--accent); primary buttons are solid var(--accent) with color #141011; selected list rows get box-shadow: inset 3px 0 var(--accent) plus background var(--accent-dim). Hover on inactive items changes only border-color to var(--glass-border-hover). Nothing else in chrome is brass-filled.
  2. Carpet vs wallpaper. Carpet vs wallpaper surface tokens: add --surface-info: rgba(20,44,50,.94) and --surface-info-raised: #1f373e to the AUREL :root; in workspace.css set body[data-workspace-appearance] { --workspace-surface: var(--surface-info); --workspace-raised: var(--surface-info-raised); --workspace-accent: var(--accent); --workspace-border: var(--glass-border); } (leave the 'field' and 'instrument' appearance blocks untouched); panel body lists (.ui-scroll), telemetry readouts, search results and #intel-hud .hud-summary use var(--surface-info); headers, dock, rails, dialogs and provider settings stay on var(--glass-bg). Replace the hardcoded #181b1d / #24282a / #bda679 fallbacks in planner.css and chronicle.css with var(--surface-info) / var(--surface-info-raised) / var(--accent) so Lens, Fieldbook, Planner and Chronicle read as one petrol room.
  3. Measured L* ladder. Measured L* ladder (grafted from Parlor Noir): ink #141011 (L* 5) -> glass #211513 (L* 8) / info #142a30 (L* 16) -> raised #2f2a2a (L* 18) and info-raised #1f373e (L* 21) for cards, inputs and chips, each with inset 0 1px 0 rgba(255,255,255,.045) as its only edge -> menu #3a3435 (L* 22) for popovers, selects and context menus, carrying --panel-surface-shadow so every popup sits visibly above the glass it opens from. No 1px outer ring; --aurel-raised is re-pointed to var(--raised) and --aurel-ink to var(--bg-dark).
  4. Three-state rule. Three-state interaction rule (grafted from Parlor Noir, implemented with the winner's colors): :focus-visible { outline: 2px solid rgba(111,167,177,.9); outline-offset: 2px } (petrol, the only teal besides scroll thumbs rgba(111,167,177,.45)); selected/active = brass seam plus var(--accent) text; hover = var(--glass-border-hover) hairline only. Focus, selection and hover never share a color, and cyan stays exclusively a map color.
  5. Dim mono eyebrows. Dim mono eyebrows: section titles, telemetry unit labels, list-group captions and HUD keys set in JetBrains Mono 10px uppercase, 0.12em tracking, color var(--text-dim) #a7a39b; teal is removed from all chrome text so brass is the only colored chrome text besides the status trio.
  6. Telemetry grid and mobile sheet. Dense telemetry grid and mobile sheet (grafted from Westview Instrument): telemetry rows in JetBrains Mono 11px (12px in HUD) with font-variant-numeric: tabular-nums at 24px line-height, unit suffixes in var(--text-secondary); the mobile bottom sheet uses var(--surface-info) with a 36x4px grab handle in var(--accent-dim), 44px minimum dock tap targets and padding-bottom: env(safe-area-inset-bottom).
  7. Wordmark scanline. Wordmark scanline: #title-bar h1 at Manrope 300, 28px, 0.3em tracking, var(--text-primary), position: relative, with a single ::after { content:''; position:absolute; left:-2%; right:-2%; top:46%; height:1px; background:var(--bg-dark); opacity:.7; pointer-events:none } scoped under :root:not([data-ui-theme='cyber']). No attr(data-text) echo, no clip-path, no animation, so RTL/CJK titles cannot render empty and prefers-reduced-motion needs no override.

Risks to watch

  • info/glass measures 1.19 and the two levels are separated mainly by hue (petrol vs oxblood) plus 7 L* points; verify at 1x on an uncalibrated monitor over daylight imagery, and if the step reads as one tone, lighten the info surface to rgba(22,48,55,.94) rather than lightening glass, so command surfaces stay the darkest thing over the globe.
  • Menu #3a3435 (L* 22.3) is only 0.8 L* above info-raised #1f373e (L* 21.5); a popover opened from an info-raised card sits at 1.04 against it. Popovers normally open over the info body (1.37) or glass (1.46), but if a select inside a Planner/Chronicle card looks flat, lift menu to #3e3839 and re-check text-dim (4.85 on menu now, little margin).
  • textDim #a7a39b lands at 4.99 on info-raised and 4.85 on menu, AA with little headroom; keep eyebrows at 10px uppercase only on glass and info panels and use var(--text-secondary) for captions inside cards and menus.
  • Danger #e8836d is 4.72 on info-raised and 4.59 on menu; keep destructive labels at 12px or larger on raised sub-surfaces and never color-only.
  • Brass #d6ab55 is warmer than the old #d7b778; over night-lights imagery at low zoom a seam at the panel edge could rhyme with city glow. Keep it to seams, buttons and selected rows inside panels, and fall back to #d9b35a if seams vanish over city glow.
  • The oxblood-tinted command glass warms the satellite imagery bleeding through at .94 alpha; if the layer under panels looks sepia, raise alpha to .95 rather than cooling the tint, and raise --glass-border to rgba(242,235,221,.18) if panel edges disappear over dark ocean now that the 1px outer ring is gone.
  • Workspace scoping: the new --workspace-* mappings must go in the base body[data-workspace-appearance] block only; the 'field' (light) and 'instrument' appearance blocks and everything under :root[data-ui-theme='cyber'] (cyber.css) stay untouched. The existing hardcoded brass literals in aurel.css (#d7b778, #f1d49a) must be replaced with var(--accent) or they will sit beside the new brass as a second gold.
