# Phase 3 design contract

The Plan destination turns a selected place or an explicitly chosen existing route into a bounded, source-labelled field snapshot. Analysis is deliberate, cancellable and local-saveable. It never runs merely because a panel opens.

Keep the graphite, ivory and brass workspace, local fonts, one inspector and existing mobile sheet. Source cards state forecast versus observation, units, retrieval and applicable times. CAMS global model context is not a local station; terrain gaps remain visible. Saved snapshots remain historical and do not silently refresh.

Core acceptance: coordinate search → selected-place analysis → current-route analysis → save → reload Library; missing heights and unavailable providers retained; no paid requests; desktop and 390px phone controls reachable. Synthetic browser fixtures must be labelled as fixtures in evidence, never reported as current Dehradun conditions.
