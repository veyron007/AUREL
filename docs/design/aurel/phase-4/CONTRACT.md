# Phase 4 design contract

Compare contains Chronicle and Research, with the existing advanced imagery tool retained. Chronicle makes two acquisition dates, sources, limits and interpretation explicit. It borrows the existing map divider and renderer; it never creates a second globe or silently substitutes current imagery for a saved date.

Research is a deliberate, bounded scientific action over a selected place. Its native-grid NDVI preview distinguishes missing pixels, states the 10 m reflectance grid and 20 m classification mask, and exposes scale, offset, processing baseline, acquisition time, attribution and method. An RGB image is never a scientific input. Raster export is local and includes provenance.

Use the AUREL graphite/ivory/brass system, quiet type and one inspector. Keep keyboard controls, status/error/empty/partial states and phone sheets. Dates and source gaps are meaningful content. Simulated validation pixels must be labelled as fixtures in evidence and never represented as actual satellite observations.
